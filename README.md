# Calorie Fit AI
เว็บแอปภาษาไทยสำหรับถ่ายรูปอาหาร วิเคราะห์แคลอรีด้วย OpenAI Vision และบันทึกอาหารรายวัน

## วิธีเปิดใช้งาน
1. ติดตั้ง Node.js 18 ขึ้นไป
2. เปิด Terminal ในโฟลเดอร์นี้ แล้วรัน `npm install`
3. คัดลอก `.env.example` เป็น `.env` และใส่ OpenAI API key จริง (ห้ามเผยแพร่ไฟล์นี้)
4. รัน `npm start`
5. เปิด http://localhost:3000 บนเครื่องที่รันเซิร์ฟเวอร์

ต้องมีอินเทอร์เน็ตและ API key ที่มีสิทธิ์ใช้งานและการคิดค่าบริการ API; การสมัคร ChatGPT ไม่ได้รวมเครดิต API โดยอัตโนมัติ

## ความสามารถ
- ถ่ายภาพด้วยกล้องมือถือหรือเลือกภาพจากเครื่อง
- วิเคราะห์ชื่ออาหาร ปริมาณ แคลอรีช่วงต่ำ-สูง โปรตีน คาร์บ ไขมันผ่าน OpenAI API
- แก้ไขชื่ออาหารและปรับปริมาณก่อนบันทึก
- คำนวณเป้าหมาย BMR/TDEE และบันทึกมื้ออาหารใน localStorage ของเบราว์เซอร์

## หมายเหตุ
- ภาพจะถูกส่งไปยัง OpenAI API เมื่อกดวิเคราะห์ ควรแจ้งผู้ใช้งานเรื่องความเป็นส่วนตัวก่อนใช้งานจริง
- ข้อมูลบันทึกอยู่เฉพาะเบราว์เซอร์เดียว และรีเซ็ตเป็นวันใหม่เมื่อเปิดแอปในวันถัดไป
- เพื่อเปิดกล้องบนมือถือที่เชื่อมผ่านเครือข่าย ควรโฮสต์ผ่าน HTTPS
- หากนำขึ้นสาธารณะ ต้องเพิ่มระบบยืนยันตัวตน จำกัดอัตราการเรียก API และการควบคุมค่าใช้จ่าย

## ใช้บน iPhone
หลังนำเซิร์ฟเวอร์ขึ้นโฮสติ้ง HTTPS และตั้งค่า OPENAI_API_KEY ที่ฝั่งเซิร์ฟเวอร์แล้ว เปิด URL ใน Safari → แชร์ → เพิ่มไปยังหน้าจอโฮม (Add to Home Screen). ใช้กล้องผ่านปุ่มถ่ายรูปในแอปได้ โดยอาจต้องอนุญาตกล้อง/รูปภาพตามที่ iOS แจ้ง แอปไม่ทำงานเป็น AI แบบออฟไลน์
